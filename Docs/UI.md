# Стол: сцены и демо-режим

## Запуск

* **F5** в редакторе — открывается `res://Scenes/Table.tscn` (прописан как main scene).
* Или `godot --path .` из консоли.
* Скриншот текущего стола: `godot --path . --script res://tools/capture_table.gd`
  → `res://Docs/table_preview.png`.

Разрешение — 1920×1080 (canvas_items + expand), окно по умолчанию 1600×900,
поэтому всё масштабируется без потери раскладки.

## Из чего собран стол

```
Scenes/Table.tscn          — стол: фон #043f09, рамка, 6 зон, рука, колода, кнопки
Scenes/CaravanView.tscn    — зона каравана: заголовок, сумма, направление, масть, стопка
Scenes/CardView.tscn       — одна карта: лицо/рубашка, бейдж K/Q, подсветка выбора/цели
Scripts/UI/TableView.gd    — рендер состояния + демо-логика (временная)
Scripts/UI/CaravanView.gd  — визуал каравана, клики по стопке и по картам
Scripts/UI/CardView.gd     — визуал карты, hover/selected/target
Scripts/UI/CardArt.gd      — AtlasTexture с обрезкой прозрачных полей PNG (90, 7, 332, 498)
```

`CardArt` режет не листы, а прозрачные поля: все 55 PNG — 512×512 с одинаковым
контентом 332×498, поэтому карта рисуется с пропорцией 2:3 без «воздуха».

## Что умеет демо-режим

`TableView.demo = true` собирает сцену-пример: рука 8 карт, три каравана игрока
(7♣, 9♥+K, 10♦+9♦+4♦ = 23), три каравана дилера (6♠+Q, 8♣+5♣, 4♥).

Управление:

| Действие | Что происходит |
|---|---|
| Клик по карте в руке | выбор, подсветка всех легальных целей (золото — зона, голубой — карта под эффект) |
| Клик по каравану | положить числовую карту в конец |
| Клик по карте каравана | сыграть эффект (J/Q/K/джокер) на эту карту |
| «Взять» | добрать карту |
| «Ход» | снять выбор, надпись в статусе |
| «Сброс» | сбросить выбранную карту и добрать |

Всё считается настоящим `KaravanRules`, поэтому в демо уже видно работу
валета (убирает карту с королём), дамы (разворот и смена масти), короля
(удвоение) и обоих режимов джокера.

## Что временно и уйдёт на шаге 4

`TableView._try_play()`, `_on_draw_pressed()`, `_on_discard_pressed()`,
`_setup_demo()` — это заглушки без очереди хода, без FSM и без дилера.
На шаге 4 появится `GameController` (START / PLAYER_TURN / DEALER_TURN /
GAME_OVER), который будет владеть состоянием, а `TableView` останется
чистым рендером: `render_hand()`, `render_caravan()`, `set_status()`.
