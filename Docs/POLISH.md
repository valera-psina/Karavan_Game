# Полировка: стол, анимации, меню, боты, звук, портрет

## 1. Главное меню

`Scenes/MainMenu.tscn` (главная сцена проекта): тёмно-зелёный фон `#043f09`,
рамка, заголовок и кнопки

| Кнопка | Действие |
|---|---|
| «Играть» | `change_scene_to_file("res://Scenes/Game.tscn")` |
| «Сложность: Легко/Сложно» | переключает `Settings.difficulty` |
| «Сменить ориентацию» | окно 1600×900 ↔ 900×1600 + холст 1920×1080 ↔ 1080×1920 |
| «Выход» | `get_tree().quit()` |

Сложность живёт в автозагрузке `Settings` и переживает смену сцены.

## 2. Боты

```
Scripts/Bots/BotBase.gd   — choose_move(), перебор легальных ходов, клоны стола
Scripts/Bots/EasyBot.gd   — первый легальный ход
Scripts/Bots/HardBot.gd   — оценка последствий хода
```

`HardBot` клонирует стол, применяет ход и считает: +45 за вход своего каравана
в 21–26, −80 за перебор, +95 за выбивание чужого каравана из зоны, бонусы за
валета по «горячему» каравану и короля на свой караван, плюс шум 0–6.

## 3. Звук

Автозагрузка `Sfx`: `AudioStreamPlayer` на каждый файл, всё через
`play(key, min_pitch, max_pitch)` / `play_sfx(player, ...)`.

| Событие | Звук | Питч |
|---|---|---|
| клик по карте в руке (выбор) | `sfx_button_click` | 0.92–1.08 |
| «Взять» | `sfx_card_draw` | 0.95–1.05 |
| любой сыгранный эффект | `sfx_card_place` | 0.9–1.1 |
| кнопки, сброс каравана | `sfx_button_click` | 0.92–1.08 |
| победа / поражение | `sfx_win` / `sfx_lose` | без рандома |

## 4. Стек карт (как в New Vegas)

`CaravanView.render()`:

* **числовые карты и тузы** — вертикальная стопка: шаг 28 px, у каждой карты
  виден левый верхний угол с номиналом и мастью;
* **валет / дама / король** — веер вправо поверх своей карты, шаг 26 px,
  клик по ним не перехватывается (целью остаётся базовая карта);
* каждая карта повёрнута случайно на −3…+3°, `z_index` растёт по порядку
  выкладывания, поэтому свежая карта всегда сверху;
* стопка центрируется по высоте зоны, лишние карты обрезаются `clip_contents`.

Размеры: карта 92×138, зона каравана 500×285 (в портрете — по ширине, 380).

## 5. Анимации

* `TableView._animate_new_cards()` сравнивает набор карт на столе с прошлым
  рендером и для новых запускает полёт: `CardView`-дубль едет по `Tween`
  из деки (или из руки — позиция запоминается при клике) к своей ячейке за
  **0.24 с**, по пути доворачивается и растворяется.
* `CardView.pop_in()` — появление карты: альфа 0→1, масштаб 0.88→1 (TRANS_BACK).
* Полетевшая карта рисуется в `%Overlay` поверх стола, реальная карта уже на месте.

## 6. Старт партии

`GameController._run_start_step()` — очередь `[дилер, игрок] × 3`:
дилер ждёт 0.4 с, кладёт карту, затем ход игрока; и так шесть раз.
Интерфейс заблокирован, пока дилер не закончил, в статусе — счётчик `n/3`.

## 7. Портрет и кнопки

* `window/handheld/orientation=6` (Sensor), `canvas_items` + `expand`,
  эмуляция тача.
* Раскладка в обоих режимах одна и та же: 3 каравана дилера сверху, 3 игрока
  снизу, рука внизу, кнопки — `%BtnArea` в правом нижнем углу (`anchors 1/1`).
  В портрете караваны делят ширину поровну (`SIZE_EXPAND_FILL`, высота 380),
  карты в руке 84×126, в ландшафте — 500×285 и 92×138.
* Ничего не пересоздаётся вручную: `_apply_orientation()` вызывает
  `size_changed`/`NOTIFICATION_RESIZED` и просто меняет размеры и флаги.
