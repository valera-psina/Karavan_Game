# Правила «Каравана» — зафиксированная версия v1

Документ описывает поведение, которое реализует `Scripts/Rules/KaravanRules.gd`.
Это «источник истины» для UI (шаг 3), game loop (шаг 4) и бота (шаг 5).
Спорные места FNV, которые в ТЗ читались двояко, зафиксированы здесь и
вынесены в константы — их можно поменять, не переписывая логику.

## 1. Цель

Собрать **2 каравана из 3** со значением **21–26**, каждый строго выше
одноимённого (по номеру слота) каравана противника.

## 2. Колода

* 54 карты: 52 стандартные + 2 джокера (`CardCatalog.standard_deck()`).
* Повторы рангов/мастей в одной колоде невозможны; «повторы только из разных
  брендов» — на будущее, поле `CardData.brand`.
* Пустая колода автоматически перемешивает сброс (`DeckData.draw()`).

## 3. Раздача и старт (реализуется на шаге 4)

* По 8 карт в руке.
* Каждый выкладывает по одной **числовой** карте на каждый из трёх своих
  караванов; рука добирается до 8.
* Первая карта каравана задаёт масть.

## 4. Ход

Одно действие за ход:

1. Сыграть карту (числовую — в конец каравана, эффект — на конкретную карту
   любого каравана, своего или чужого), затем добрать карту.
2. Сбросить карту и добрать.
3. Сбросить весь караван в сброс (нельзя в первый ход партии; сам сброс
   каравана реализует контроллер, правила для него не нужны).

## 5. Легальность числовых карт

`KaravanRules.can_place_numeric()`:

| Ситуация | Можно? |
|---|---|
| Караван пуст | да (задаёт масть) |
| В караване одна числовая карта (направление ещё не задано) | да |
| Масть карты совпадает с текущей мастью каравана | да, **независимо от направления** |
| Направление ↑ и ранг карты больше ранга последней числовой | да |
| Направление ↓ и ранг карты меньше ранга последней числовой | да |
| Иначе | нет |

Детали:

* Направление задаёт **вторая** числовая карта: `sign(ранг2 − ранг1)`.
  Если ранги равны, направление остаётся `0` (дальше можно любую карту).
* Туз — числовая карта со значением 1 и рангом 1.
* Текущая масть каравана меняется на масть любой положенной карты **другой**
  масти (и на масть дамы). Это правило ТЗ «масть можно сменить, положив карту
  другой масти».
* После удаления карт валетом/джокером масть и направление сохраняются, пока
  караван не опустеет; пустой караван сбрасывает и масть, и направление.
* Раскладка карт «в середину» не поддерживается: числовая всегда в конец,
  эффект — на конкретную позицию.

## 6. Эффекты

Эффекты играются на **любой** караван (свой или противника) и на конкретную
позицию (`entry_index`); сыгранная карта-эффект уходит в сброс (кроме короля и
дамы, которые остаются прикреплёнными к позиции).

| Карта | Что делает | Остаётся на столе |
|---|---|---|
| **Валет (J)** | Удаляет позицию, на которую сыгран, **вместе со всеми прикреплёнными** картами (королями/дамами) | нет, уходит в сброс |
| **Дама (Q)** | Переворачивает направление (`direction = -direction`, `0 → 0`), задаёт масть каравана = масть дамы | да, прикреплена к позиции |
| **Король (K)** | Удваивает номинал позиции; короли складываются: 1 король ×2, 2 короля ×4 | да, прикреплён |
| **Джокер на числе** | Удаляет **все** позиции с таким же рангом **по всему столу** (оба игрока), вместе с прикреплёнными | нет |
| **Джокер на тузе** | Удаляет **все** позиции той же масти **по всему столу**, вместе с прикреплёнными | нет |

Джокера нельзя играть на пустой караван или на карту-эффект: цель обязана быть
числовой картой (туз — можно).

Размах джокера регулируется константой `JOKER_PURGES_WHOLE_TABLE`
(`false` — чистит только целевой караван). Сложение королей —
`KINGS_STACK` (`false` — второй король ничего не добавляет).

## 7. Перебор, продажа, победа

* Значение каравана — сумма номиналов позиций с учётом королей; J/Q/K сами
  очков не дают.
* **> 26 — перебор (busted)**. Ход, приводящий к перебору, **разрешён**:
  игрок может «сломать» караван, а валетом/джокером — починить его обратно.
* Караван **продан**, если `21 ≤ value ≤ 26` и `value > эффективного значения
  каравана противника` (для противника с перебором эффективное значение = 0).
* Победа — **2 проданных каравана из 3** (`KaravanRules.winner()` возвращает
  `1` / `-1` / `0`, где `0` — ещё не решено). При равенстве числа проданных
  караванов игра не решена.

## 8. Что отдаёт `apply()`

`KaravanRules.apply(card, caravans, caravan_index, entry_index)` возвращает
массив событий для UI/анимаций:

| type | Когда | Поля |
|---|---|---|
| `place` | положена числовая карта | `caravan`, `entry_index`, `card` |
| `attach` | прикреплены K или Q | `caravan`, `entry_index`, `card`, `entry_value` |
| `flip` | дама перевернула направление | `caravan`, `direction`, `suit` |
| `remove` | валет/джокер удалил позицию | `caravan`, `entry_index`, `entry`, `reason` |
| `joker` | джокер сработал | `caravan`, `entry_index`, `by` (`rank`/`suit`), `value` |
| `reset` | караван опустел | `caravan` |

Пустой массив = ход нелегален и состояние не изменилось.
